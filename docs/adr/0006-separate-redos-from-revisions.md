# Separate Redos from Revisions

Changes to analysis inputs create a Redo and start a new Analysis Lineage, resetting the visible review history because the basis of the output changed. Feedback supplied during Final Review creates a Revision within the current lineage, where versions remain available for comparison and any Revision can be selected directly as the Current Revision; this distinction prevents materially different analyses from being presented as comparable corrections while preserving iterative review.
